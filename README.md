# Diffusion Gallery

🌐 [English](README.en.md) · **日本語** · [简体中文](README.zh-CN.md) · [한국어](README.ko.md)

Stable Diffusion などの AI 生成画像を整理・閲覧するためのビューワーソフトです（旧名: PNG Metadata Viewer）。

PNG を中心に、メタデータ表示、LoRA / モデル系統の管理、サムネイル一覧、タグ集計、重複検出、ロゴオーバーレイ、そして音楽・音声・スライドショーを統合した HMV（Hype Music Video）までを 1 つのデスクトップアプリにまとめています。

AI 画像の制作・整理・確認と相性がよく、生成時のプロンプトや LoRA 情報を見ながら運用しやすいのが特徴です。

## Highlights

- `PySide6` ベースの 3 ペイン GUI
- 高速なスキャン、閲覧、サムネイル表示
- PNG メタデータ解析と表示
- LoRA / モデル情報の一覧管理と検索
- モデル系統の自動判定: SD/SDXL/Pony/Illustrious/NoobAI/Flux/Anima など 17 系統をモデル名・生成環境指紋・LoRA 名から分類し、バッジ表示・フィルタ・手動タグ付けで管理
- 拡張検索: タグ・ファイル名・除外語・完全一致フレーズ・正規表現・日付/解像度/サイズ/Steps/CFG 範囲・検索履歴（「🔍詳細」パネル）
- 重複検出、評価、Favorites、タグ集計
- HMV（Hype Music Video）: 音楽・音声・スライドショーの再生/一時停止/停止、曲順シャッフル、拍・フレーム数・速度、切替アニメ、波形同期・ビート検出・BPM 拍同期、SFW／NSFWフィルターとブロック交互再生に対応
- 音声リアクティブ効果: EDM の低音・オンセットに合わせて拍ズーム、輪郭だけのパルス/発光、波紋、パーティクル、任意のフラッシュを再生
- ロゴオーバーレイ
- キャッシュを活かした軽快なフォルダ運用
- 英語・中国語（簡体）・韓国語対応（環境設定の「言語 / Language」タブで選択。再起動で反映）

## HMV（Hype Music Video）

音楽・音声・スライドショーをまとめて **HMV** と呼びます。

- **▶ / ⏸ スライド**: 再生と一時停止を1つのボタンで切り替えます。一時停止しても画像・音声の位置は保持され、再再生時に最初へ戻りません。
- **⏹ スライド停止**: 別ボタンでHMVを停止し、画像・音声を先頭へ戻します。
- **2段組ツールバー**: 上段にファイル情報・音楽・設定・閉じる、下段にスライド操作と表示操作を配置しています。
- **スライドプリセット**: 🔊ポップアップで間隔・切替アニメ・BPM／波形同期・曲順・リアクティブ効果・タグ選別・安全性フィルターを名前付き保存できます。適用／削除にも対応しています。
- **曲をランダム再生**: 🔊ポップアップまたは環境設定の **🎵 HMV** タブで切り替えます。OFFはファイル名順です。
- **スライドタグ**: 🔊ポップアップの「タグを選択...」から、プロンプトのACT（`paizuri`、`fellatio` など）、作品LoRA、キャラクター・一般タグを選別できます。複数タグは「同じタグの画像を連続表示」が既定で、タグごとのまとまりを保ったまま全体をシャッフルします。
- **SFW／NSFW表示**: Positiveプロンプトから自動判定し、セル右上とFullViewerの情報ラベルに表示します。プロンプトがない画像は「未分類」です。グリッド／FullViewerの右クリックから手動で「自動判定／SFW／NSFW」を変更でき、選択画像の一括変更にも対応します。
- **安全性フィルター**: 🔊ポップアップで「すべて（未分類を含む）／SFWのみ／NSFWのみ／SFW＋NSFWを交互」を選択できます。単独表示と交互表示では未分類画像を除外します。
- **交互再生**: 「SFW＋NSFWを交互」は、SFW／NSFWをそれぞれ最大6枚のランダムな塊にして交互に流します。キャラクター単位で交互させたい場合は、そのキャラクタータグ／LoRAをスライドタグで選択してください。選択タグごとに交互順を維持し、未選択なら全画像を交互します。
- 設定ダイアログは拡大済みです。数値スピンボックス上のマウスホイールは値を変えず、ダイアログのスクロールに使われます。

## 音声リアクティブ効果（EDM）

環境設定の **🎵 HMV** タブにある **「音声に合わせて画像を変化」** を有効にすると、BGM の再生位置に同期して約30fpsで効果を描画します。既定は無効です。

- **輪郭パルス**: 画像内部は変えず、輪郭だけを拍に合わせて強調・拡縮・発光させます。既存のスライド切替「パルス」とは別の設定・別の描画処理です。
- **拍ズーム / 波紋 / パーティクル**: 低音とオンセットの強さに応じて再生します。
- **フラッシュ**: 既定は無効です。有効にする場合も「フラッシュを抑える」を推奨します。点滅に敏感な方は有効にしないでください。
- **強度 / 同期オフセット**: 効果の強さと、音声に対して描画をずらす時間を調整できます。

波形同期の有効・無効に関係なく利用できます。初回解析時は30秒窓ごとに輪郭・発光を先行描画し、最終的に曲全体の特徴量へ置き換えます。以降はキャッシュを再利用します。

## Tech Points

- `QThread` / `QRunnable` / `QThreadPool` を使って UI を止めない設計
- `QSplitter` ベースの柔軟なレイアウト
- Pillow と Qt を組み合わせた画像処理
- `librosa` による波形・ビート解析（窓分割で低メモリ、結果をキャッシュ）
- `QMediaPlayer` と `QGraphicsScene` / `QTimer` によるスライド演出と音声同期
- ローカルキャッシュと永続化設定で再起動後も使いやすい構成
- 単体スクリプトとして配布しやすい実装

## Requirements

- Python 3.11+
- Windows 10 / 11

```bash
pip install -r requirements.txt
python png_viewer.py
```

## Optional Environment Variables

- `PNG_VIEWER_DEFAULT_FOLDER`
  - 起動時に最初に開くフォルダを指定します（環境変数名は旧名のまま据え置き）

```powershell
$env:PNG_VIEWER_DEFAULT_FOLDER = "D:\Images"
python .\png_viewer.py
```
